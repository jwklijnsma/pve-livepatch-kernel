# Contributing and license

## Contributing

Catalog entries, test reports and code are welcome:

- Questions and ideas: [GitHub Discussions](https://github.com/jwklijnsma/pve-livepatch-kernel/discussions)
- Bugs and CVE requests: [issues](https://github.com/jwklijnsma/pve-livepatch-kernel/issues/new/choose)
- How to contribute: [CONTRIBUTING.md](https://github.com/jwklijnsma/pve-livepatch-kernel/blob/main/CONTRIBUTING.md), [Code of Conduct](https://github.com/jwklijnsma/pve-livepatch-kernel/blob/main/CODE_OF_CONDUCT.md)
- Vulnerabilities: privately, see [SECURITY.md](https://github.com/jwklijnsma/pve-livepatch-kernel/blob/main/SECURITY.md)
